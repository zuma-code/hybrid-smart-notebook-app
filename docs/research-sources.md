- [Roam Research](https://roamresearch.com/) - Base de conocimiento con enlaces bidireccionales

- [Bear](https://bear.app/) - Editor de notas con soporte para código
- [TiddlyWiki](https://tiddlywiki.com/) - Cuaderno no lineal en un solo archivo HTML

## Notas Resumidas

### Modelos de Organización de Notas

1. **Daily Journal Model**: Enfoque en notas diarias con timeline visual
2. **Graph Knowledge Base**: Notas interconectadas con vista gráfica (estilo Obsidian)
3. **Block-Based Workspace**: Bloques modulares tipo Notion
4. **Zettelkasten**: Sistema de tarjetas con IDs únicos y estructura de enlaces
5. **Hybrid Smart Notebook**: Combinación de daily notes + concept library + prompt vault

### Características Clave Identificadas

- **Markdown Support**: Formato universal para notas
- **Syntax Highlighting**: Esencial para código en notas de programación
- **Bidirectional Links**: Enlaces bidireccionales entre conceptos
- **Tag System**: Organización flexible con tags
- **Image Support**: Almacenamiento y organización de imágenes
- **Search**: Búsqueda global y semántica
- **Dark Mode**: Tema oscuro para desarrollo
- **Mobile Responsive**: Acceso desde cualquier dispositivo

### Decisiones Técnicas

- **Next.js 14+**: Framework moderno con App Router
- **SQLite → PostgreSQL**: Empezar simple, escalar después
- **TipTap**: Editor flexible y extensible
- **Prisma**: Type-safety y migraciones fáciles
- **Fuse.js**: Búsqueda client-side sin backend adicional
